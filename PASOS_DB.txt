# PASOS PARA CORREGIR LA BASE DE DATOS (POSTGRESQL)

## Opción 1: Con DBeaver (RECOMENDADO)

DBeaver es un programa para administrar bases de datos. Ya lo tienes instalado.

### Paso 1: Abrir DBeaver
- Busca "DBeaver" en tu PC y ábrelo

### Paso 2: Conectar a PostgreSQL
- En el panel izquierdo, busca tu conexión "postgresql" o "localhost"
- Si no tienes conexión, crea una nueva:
  - Click derecho en " PostgreSQL" > "New Connection"
  - Host: localhost
  - Port: 5432
  - Database: pos_test
  - Username: postgres
  - Password: postgres
- Doble click en la conexión para conectar

### Paso 3: Abrir Editor SQL
- Click en el botón "SQL" (o presiona Ctrl+Enter) en la barra de herramientas

### Paso 4: Ejecutar el SQL
- Copia todo el contenido del archivo `FIX_DATABASE_SQL.txt`
- Pega en el editor SQL de DBeaver
- Presiona Ctrl+Enter o el botón "Execute" (play verde)

### Paso 5: Verificar
- Deberías ver mensajes de éxito
- Si dice "relation already exists" está bien, significa que ya estaba
